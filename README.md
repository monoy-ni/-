# 课程设计系统

本次修订用于解决规范展示与页面实际样式不一致的问题。依据用户提供的《设计系统基础变量.html》参数表；当前为待用户复核的修订稿，不沿用旧版已认可的状态。

- `tokens.json` 是变量与文字角色的唯一维护来源。
- `tokens.css` 和 `tokens.js` 由 `node build-tokens.mjs` 生成，不单独修改。
- `system.css` 维护共享组件和排版角色。
- `course-layout.css`、`opening-layout.css`、`wardrobe-lesson.css` 负责页面组合，引用共享变量，不维护另一套文字参数。
- `docs.js` 的规范样张读取 `tokens.js`，避免展示数值与实际样式分离。
- 四个页面入口均引用外部共享 CSS；课程页与总览不再内嵌变量副本。
- 产品板块正文存放在 `课程内容页.html` 的三个 `product-*-body` 模板中；`product-lesson.css` 只负责组合，标题、正文、情境示例与图注继续使用共享文字角色。
- 开发板块的项目协作正文存放在 `collaboration-course-body` 模板中，按用户提供的 C 语言小组作业例子整理；通过 `course-reading` 复用上述正文排版，案例仍使用辅助信息角色。内容待用户审阅。
- 自行车 PRD 在课程第三个主题中用同站点 iframe 阅读。`assets/自行车prd.docx` 是原件；运行 `python3 build-bicycle-prd.py` 生成 `bicycle-prd.html`，包括原文的 14 项功能需求和 3 张内嵌电子表格。生成页不单独维护另一份正文，也不依赖外部文档预览服务。

主标题为 48 / 1.2 / 500，副标题为 24 / 1.4 / 500，正文为 16 / 1.8 / 400，辅助信息为 13 / 1.6 / 400。金句为 24 / 1.6 / 400，使用独立字体职责；实际操作提示保持信息文字。

颜色保留原值。栅格、断点、页面宽度和交互实现中属于推导或项目选择的部分，保持相应标注，不写成原文已确认的规定。兼容名称如 `font-size.h1`、`shadow.sm` 指向现有角色，不代表新增设计层级。

修改后运行 `node build-tokens.mjs` 和 `node verify.mjs`，并检查规范页、组件、模板与课程页的实际显示。技术检查不代替用户对设计效果的判断。
