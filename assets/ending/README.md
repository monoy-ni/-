# 05 结尾素材

- `corkboard.png`：用户在本轮提供的第二张软木便签板素材，保留原始图片，作为墙面背景。
- 纸张、格纹衬纸和红色图钉：依据用户提供的第一张素材，用 HTML、CSS 和 SVG 绘制。五张纸上的语录采用用户原文。
- `../fonts/ending-qingchun.woff2`：来自用户本机的 `鸿雷小纸条青春体.ttf`，仅保留这五张语录及结尾标题所需字形，转换为 WOFF2（113 个字符，37,388 字节）。保留原字体的名称、版权及嵌入标记，未修改字形。字体原始版权记录为 `Typeface @ (鸿雷字记).2025.All Rights Reserved`；原文件未附授权说明。

字体子集专用于当前固定语录。修改语录时须从原字体重新生成子集并核对新增字形，不应直接假定它包含全部汉字。
